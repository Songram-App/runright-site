SUSTAINABILITY

Track the environmental impact of your CI infrastructure. Measure CO₂ emissions and report on green initiatives.

Carbon Footprint Tracking

CORE

Calculate CO₂ emissions per job using provider-specific emission factors (AWS: 0.417, GCP: 0.180, Azure: 0.350 kg CO₂/kWh). Track total emissions and saveable carbon.

Sustainability KPIs

CORE

Report carbon metrics in relatable terms: tree days equivalent, car miles avoided. Build the case for green CI initiatives with concrete data.

GOVERNANCE & AUTOMATION

Set guardrails, enforce policies, and route alerts to the right teams automatically.

Policy Automation

CORE

Set max cost/hour guardrails at global, repository, or job scope. Policies cascade with job-level overrides. Fail CI automatically when thresholds are exceeded.

  • --fail-if-oversized N exit codes
  • --max-cost-per-hour N limits
  • Scope precedence: job > repo > global

Alert Routing

CORE

Route cost threshold violations, waste alerts, and savings regressions to Slack, Teams, email, or webhooks. Team-based routing ensures the right people see the right signals.

Agent Auto-Update

NEW

Self-updating agent pulls from GitHub releases. Choose stable, beta, or nightly channels. Run runright update to upgrade in place.
